## 🎯 Learning Path

### Phase 1: HTML Fundamentals — Days 1-4

- Learn the basic HTML document structure
- Work with headings and paragraphs
- Create links and bookmarks
- Learn about images, lists and tables
- Understand basic meta tags

### Phase 2: Forms & Structure — Days 5-7

- Create HTML forms
- Work with different input elements
- Understand block and inline elements
- Use `<div>` and `<span>`
- Work with `id` and `class` attributes
- Apply CSS using IDs and classes

### Phase 3: Multimedia & HTML5 — Days 8-11

- Add audio and video to webpages
- Work with SVG
- Embed external content using iframes
- Understand semantic HTML elements
- Use HTML entities and special characters
- Display formatted code using `<pre>` and `<code>`
